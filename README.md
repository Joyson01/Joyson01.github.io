# Joyson Vadlya’s portfolio

A static portfolio hosted on [joyson01.me](https://joyson01.me/) through GitHub Pages. The site uses HTML and CSS with locally hosted fonts.

Preview from this directory with:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). Edit page content in `index.html` and styling in `styles.css`. GitHub Pages serves the repository root on `main` and takes its custom domain from `CNAME`.
